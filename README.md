# ✈️ Airline Customer Satisfaction Analysis

Exploratory Data Analysis of airline passenger survey data to understand **customer satisfaction, service quality, passenger segments, and flight delays** using Python.


## 🛠️ Tools Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## 📌 Dataset

* **25,976** passenger records
* Passenger demographics and travel details
* 14 airline service ratings
* Departure and arrival delays
* Customer satisfaction status

## 🔧 Key Work Performed

* Data cleaning and handling missing values
* Data type correction
* Feature engineering using average service ratings
* Exploratory data analysis
* Passenger segment analysis
* Service and delay analysis
* Data visualization using Matplotlib and Seaborn

## 📈 Key Insights

* Overall customer satisfaction was **43.9%**
* Inflight Wi-Fi received the lowest average rating
* Inflight service received the highest average rating
* Business class showed higher satisfaction than Economy
* Online boarding had a strong relationship with satisfaction
* Departure and arrival delays were strongly correlated
